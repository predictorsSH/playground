# C# 튜토리얼: 빈칸을 채우면서 배우기

Python을 쓰다가 C#으로 넘어올 때 걸리는 지점들을 12개 레슨으로 나누어 담았습니다.
각 레슨 파일에는 `TODO` 표시가 붙은 빈칸이 들어 있습니다. 그 빈칸을 채운 뒤에 실행하면
항목마다 통과 여부가 바로 표시됩니다.

## 실행 방법

```bash
dotnet run          # 레슨 목록을 출력합니다
dotnet run 01       # 1번 레슨만 채점합니다
dotnet run all      # 12개 레슨을 한꺼번에 채점합니다
```

채점 결과는 다음과 같은 모양으로 출력됩니다.

```
-- 2. 정수 나눗셈과 실수 나눗셈
   PASS 정수 나눗셈 7 / 2
   FAIL 실수 나눗셈 7 / 2
        기대값 3.5 / 실제값 3

레슨 01: 1개 통과, 1개 실패
```

`FAIL` 아래에 기대값과 실제값이 함께 나오므로, 어느 부분을 잘못 채웠는지 확인할 수 있습니다.

## 진행 방법

1. `Lessons/Lesson01.cs` 파일을 엽니다. 파일 맨 위의 주석에 그 레슨에서 배울 내용이 정리되어 있습니다.
2. `TODO` 표시가 붙은 줄만 고칩니다. `Check.` 로 시작하는 줄은 채점에 쓰이므로 수정하지 않습니다.
3. `dotnet run 01` 명령으로 채점합니다. 모든 항목이 `PASS` 로 바뀌면 다음 레슨으로 넘어갑니다.
4. 풀리지 않는 항목이 있으면 `answers/Lesson01.md` 파일을 엽니다. 여기에 적힌 코드가 유일한 정답은 아닙니다.
   채점만 통과한다면 다른 방식으로 작성해도 괜찮습니다.

빈칸을 아직 채우지 않은 상태에서도 프로젝트는 정상적으로 컴파일됩니다. 값이 맞지 않아서
채점에서 걸릴 뿐입니다. 또한 레슨 코드가 도중에 예외를 일으켜도 러너가 그 예외를 잡아서
어디에서 멈췄는지 알려 주고, 이어서 다음 레슨을 채점합니다.

## 레슨 구성

| 번호 | 주제 | 다루는 내용 |
| --- | --- | --- |
| 01 | 타입과 변수 | int, double, decimal, var, 정수 나눗셈, 문자열 보간, const |
| 02 | 형변환과 파싱 | 캐스팅, Parse, TryParse, out, 서식 지정 |
| 03 | 조건문, 반복문, 패턴 매칭 | if, 삼항 연산자, for와 while과 foreach, switch 식, 관계 패턴 |
| 04 | 메서드 | 반환 타입, 오버로딩, 선택적 매개변수, out, 튜플, params |
| 05 | 배열과 컬렉션 | 배열, List, Dictionary, HashSet |
| 06 | 클래스와 레코드 | 프로퍼티, 생성자, ToString 재정의, struct, record, static |
| 07 | 인터페이스와 상속 | interface, abstract, virtual과 override, 타입 패턴 |
| 08 | null 다루기 | nullable 참조 타입, `?.`, `??`, `??=`, `int?` |
| 09 | LINQ | Where, Select, 집계, 정렬, GroupBy, 지연 실행 |
| 10 | 예외 처리와 파일 입출력 | try와 catch와 finally, 사용자 정의 예외, File, using |
| 11 | async와 await | Task, await, Task.WhenAll, 비동기 예외 |
| 12 | 제네릭과 델리게이트 | 제네릭 메서드와 클래스, 제약 조건, Func와 Action, 확장 메서드 |

앞 레슨에서 익힌 문법이 뒤 레슨에 계속 다시 나옵니다. 01번부터 순서대로 진행하는 편이 좋습니다.

## 파일 구성

```
Program.cs          레슨을 실행하고 채점하는 러너입니다. 수정할 일이 없습니다
Check.cs            채점에 쓰이는 assert 헬퍼입니다. 수정할 일이 없습니다
Lessons/            레슨 파일이 들어 있습니다. 이 안의 파일을 고치면서 학습합니다
answers/            레슨별 정답이 들어 있습니다
```

예제에 등장하는 데이터는 `P-1101A` 같은 장비 태그와 압력 측정값입니다. 문법을 익히는 동안
낯선 소재 때문에 흐름이 끊기지 않도록, 12개 레슨에서 같은 소재를 계속 사용합니다.

## Python과 달라지는 지점

| 상황 | Python | C# |
| --- | --- | --- |
| 변수 선언 | `x = 3` | `int x = 3;` 또는 `var x = 3;` |
| 나눗셈 | `7 / 2` 의 결과는 3.5 | `7 / 2` 의 결과는 3 (양쪽 모두 int이기 때문입니다) |
| 블록 구분 | 들여쓰기 | 중괄호 `{ }` |
| 조건식 | 빈 문자열이나 0도 거짓으로 취급 | bool만 올 수 있음 |
| 문자열 보간 | `f"{x}"` | `$"{x}"` |
| 값이 없음 | `None` | `null` |
| 목록 | `list` | `List<T>` |
| 사전 | `dict` | `Dictionary<K, V>` |
| 컴프리헨션 | `[f(x) for x in xs]` | `xs.Select(f)` |
| 예외 처리 | `try` 와 `except` | `try` 와 `catch` |
| 파일 열기 | `with open(...) as f:` | `using (var f = ...)` |
| 문자열 길이 | `len(s)` | `s.Length` |
| 목록 길이 | `len(xs)` | `xs.Count` (배열은 `xs.Length`) |

각 레슨 파일의 첫머리 주석에도 그 레슨에 해당하는 Python과의 대응 관계를 적어 두었습니다.
